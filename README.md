# MOT'S HAIR COUNTER（Hair Loss Counter）

抜けゆく髪を写真で数えて記録するWebアプリです。写真も解析も記録も、利用者の端末の中だけで完結します。

- インストール不要（ブラウザで開くだけ。ホーム画面に追加もできます）
- 通信なし（ページのCSPで外部への通信を禁止。機内モードで動きます）
- アカウントなし、サーバー側の保存なし、アクセス解析なし、広告なし
- 9か国語（日本語・English・中文・한국어・Deutsch・Français・Español・Italiano・Português）。ブラウザの言語にいちばん近いものを表示し、画面の下で切り替えられます

## 使い方
1. 「01 比較物を指定する」で、毛の横に置く硬貨を選ぶ（硬貨の種類は、最初は言語と地域に合わせて選ばれています）
2. 洗面台などに毛を置き、横にその硬貨を1つ置く
3. 「02 3枚撮る」で、同じ場所を真上・少し右・少し左の3枚撮る（順番は自由。「カメラで撮る」でも「写真を選ぶ」でもよい）
4. 「解析する」。硬貨は自動で見つかり、硬貨がいちばん丸く写った写真（真上から撮ったもの）が基準になる

### 「カメラで撮る」で開くカメラ
Webページは、スマホのカメラアプリの設定を読むことも、メーカーの画像処理（HDRやフラッシュの事前測光）を使うこともできません。そこで、開くカメラを2つから選べるようにしています（「設定」で切り替え）。

- スマホ本体のカメラ（スマホでの初期設定）: 本体のカメラアプリが開き、ふだん撮るのと同じ画質で撮れます。フラッシュと画質は本体のカメラの画面で設定します。1枚撮るごとにアプリへ戻ります。
- アプリ内カメラ（パソコンでの初期設定）: いちばん高い解像度で3枚続けて撮れます。ライトは「撮る瞬間のフラッシュ」ではなく点けたまま（トーチ）にして、カメラに明るさを合わせさせます。撮った写真の白飛びを調べ、多ければ露出を下げて撮り直します。閉じるとカメラを解放するので、スマホの設定は変わりません。

どちらで撮った写真も、そのままではスマホのギャラリーには残りません（アプリのメモリの中だけ）。残したいときは、撮ったあとに出る「撮った写真を端末に保存」を押すと、ダウンロードフォルダに保存されます。

### 記録が増えたとき
記録は月ごと（1年を超えたら年ごと）の1行にまとまり、開いているのはいちばん新しい月だけです。行を押すとその月の記録が開きます。グラフは、30回を超えると「直近30回・3か月・1年・すべて」を選べ、点が多いときは日・週・月・年の平均に自動でまとめます。

本数は目安です。医療機器ではなく、診断や治療の判断はしません。

## 外に出ていないことの確かめ方
- スマホを機内モードにして、撮影から記録まで使う
- 画面の下の「このアプリについて」を開くと、外部への通信の件数（0件）が見られる
- `pwa/index.html` の先頭にある Content-Security-Policy を読む（`connect-src 'none'`）
- `pwa/app.js` と `pwa/engine.js` に `fetch` / `XMLHttpRequest` / `WebSocket` がないことを検索で確かめる

通信が起きるのは、ブラウザがこのアプリ自身のファイルを取りに行くとき（初回と更新確認）だけです。

## 構成
| パス | 内容 |
|---|---|
| `pwa/` | 公開しているアプリそのもの（このフォルダを静的サイトとして配信） |
| `pwa/i18n.js` | 画面の文言（9か国語）。画面に出す文字はすべてここに置く |
| `pwa/bg/` | 背景の画像（大理石とレリーフ）。スクロールに合わせて別々の速さで動く |
| `src/engine.js` | 解析エンジン（素のJavaScript、依存なし）。`build_pwa.py` が `pwa/engine.js` にコピーする |
| `build_pwa.py` | エンジンのコピーと、`pwa/sw.js`（オフライン用）の生成 |
| `tools/gen_free.py` | 正解本数つきの合成テスト写真を作る（Python, OpenCV, numpy） |
| `tools/gen_icons.py` | アプリのアイコンを描く（Python, Pillow） |
| `test/` | エンジンの確認（Node）と、画面の通しテスト（ヘッドレスChrome） |
| `docs/PUBLISH.md` | 公開と更新の手順 |

## 開発
```
python build_pwa.py                      # pwa/ を更新
cd pwa && python -m http.server 8000     # http://localhost:8000 で試す

npm install
python tools/gen_free.py                 # test/free/ に合成写真を作る
node test/free.js 3                      # エンジンの確認
node test/i18n.js                        # 9か国語の文言に抜けがないかの確認
node test/pwa.js                         # 言語の判定、撮影、解析、記録、オフラインまでの通しテスト
```
`pwa/` のファイルを直したら、必ず `python build_pwa.py` を実行してからコミットします（オフライン用キャッシュの名前が変わり、利用者の端末に新しい版が入ります）。

## 仕組み（概要）
1. 台の色・反射・置いてある物を見分け、毛を強調する（明るさの比 → 暗い毛もツヤで明るく光る部分も同じ向きの「線」として合算 → DoG → 12方向の線フィルタ）
2. 2・3枚目を1枚目に位置合わせし、1枚目で反射に隠れた所を埋める
3. 細線化（階段状の余分な画素と短いひげを除く）して、交差点で向きの連続性からつなぎ分け、1本ずつたどる。交差点の中も線でつなぎ、台やマットの縁（片側だけ明るさが違う線）と粉ぼこりの点の連なりは除く
4. 硬貨を自動で探し（明るさの勾配で円の中心を投票 → 縁が一周そろっていて中が塗りつぶされた円だけを硬貨とみなす）、その大きさから縮尺を決めて長さを測る。カードは写真をタップして指定
5. 本数は、補正前は「長さ合計 ÷ 長い方から1割の線の平均長」。利用者が手で数えた本数を登録すると、`sqrt(線の数 × 長さ合計 / Leff)` に切り替わる（Leff は利用者ごと）
