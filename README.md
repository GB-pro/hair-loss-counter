# Hair Loss Counter

抜け毛を写真で数えて記録するWebアプリです。写真も解析も記録も、利用者の端末の中だけで完結します。

- インストール不要（ブラウザで開くだけ。ホーム画面に追加もできます）
- 通信なし（ページのCSPで外部への通信を禁止。機内モードで動きます）
- アカウントなし、サーバー側の保存なし、アクセス解析なし、広告なし

## 使い方
1. 洗面台などに毛を置き、横に硬貨を1つ置く
2. 「カメラで撮る」で、同じ場所を真上・少し左・少し右の3枚撮る（順番は自由。「写真を選ぶ」でまとめて選んでもよい）
3. 硬貨の種類を選んで「解析する」。硬貨は自動で見つかり、硬貨がいちばん丸く写った写真（真上から撮ったもの）が基準になる

アプリ内のカメラは、撮るときだけ最大の解像度とフラッシュ（使える端末のみ）を使います。閉じるとカメラを解放するので、スマホの設定は変わりません。カメラの映像も端末の外には出ません。iPhoneのSafariなど、ブラウザからフラッシュを操作できない端末ではフラッシュなしで撮ります。

本数は目安です。医療機器ではなく、診断や治療の判断はしません。

## 外に出ていないことの確かめ方
- スマホを機内モードにして、撮影から記録まで使う
- 画面右上の「通信なし」を押すと、外部への通信の件数が見られる
- `pwa/index.html` の先頭にある Content-Security-Policy を読む（`connect-src 'none'`）
- `pwa/app.js` と `pwa/engine.js` に `fetch` / `XMLHttpRequest` / `WebSocket` がないことを検索で確かめる

通信が起きるのは、ブラウザがこのアプリ自身のファイルを取りに行くとき（初回と更新確認）だけです。

## 構成
| パス | 内容 |
|---|---|
| `pwa/` | 公開しているアプリそのもの（このフォルダを静的サイトとして配信） |
| `src/engine.js` | 解析エンジン（素のJavaScript、依存なし）。`build_pwa.py` が `pwa/engine.js` にコピーする |
| `build_pwa.py` | エンジンのコピーと、`pwa/sw.js`（オフライン用）の生成 |
| `tools/gen_free.py` | 正解本数つきの合成テスト写真を作る（Python, OpenCV, numpy） |
| `test/` | エンジンの確認（Node）と、画面の通しテスト（ヘッドレスChrome） |
| `docs/PUBLISH.md` | 公開と更新の手順 |

## 開発
```
python build_pwa.py                      # pwa/ を更新
cd pwa && python -m http.server 8000     # http://localhost:8000 で試す

npm install
python tools/gen_free.py                 # test/free/ に合成写真を作る
node test/free.js 3                      # エンジンの確認
node test/pwa.js                         # オンライン→オフラインの通しテスト
```
`pwa/` のファイルを直したら、必ず `python build_pwa.py` を実行してからコミットします（オフライン用キャッシュの名前が変わり、利用者の端末に新しい版が入ります）。

## 仕組み（概要）
1. 台の色・反射・置いてある物を見分け、毛を強調する（明るさの比 → 暗い毛もツヤで明るく光る部分も同じ向きの「線」として合算 → DoG → 12方向の線フィルタ）
2. 2・3枚目を1枚目に位置合わせし、1枚目で反射に隠れた所を埋める
3. 細線化（階段状の余分な画素と短いひげを除く）して、交差点で向きの連続性からつなぎ分け、1本ずつたどる。交差点の中も線でつなぎ、台やマットの縁（片側だけ明るさが違う線）と粉ぼこりの点の連なりは除く
4. 硬貨を自動で探し（明るさの勾配で円の中心を投票 → 縁が一周そろっていて中が塗りつぶされた円だけを硬貨とみなす）、その大きさから縮尺を決めて長さを測る。カードは写真をタップして指定
5. 本数は、補正前は「長さ合計 ÷ 長い方から1割の線の平均長」。利用者が手で数えた本数を登録すると、`sqrt(線の数 × 長さ合計 / Leff)` に切り替わる（Leff は利用者ごと）
